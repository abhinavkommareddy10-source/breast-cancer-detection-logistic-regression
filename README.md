# Breast Cancer Detection Using Logistic Regression

This project analyzes breast cancer diagnostic data and builds a logistic regression model to classify tumors as malignant or benign.  
The focus of the project is on **data analysis, preprocessing, feature exploration, and model evaluation**.

---

## Dataset

The dataset used is the **Breast Cancer Wisconsin Diagnostic Dataset**, which contains 569 records with 30 numerical features extracted from digitized images of breast mass cell nuclei.

Features describe characteristics such as:

- radius
- texture
- perimeter
- area
- smoothness
- compactness
- concavity
- symmetry

The target variable classifies tumors as:

- **Malignant (M)**
- **Benign (B)**

---

## Project Workflow

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory data analysis (EDA)
4. Feature correlation analysis
5. Train-test split
6. Logistic regression model training
7. Model evaluation using:
   - Accuracy
   - Precision
   - Recall
   - Confusion Matrix

## Results

The logistic regression model was used to classify breast cancer cases based on diagnostic features.  
Evaluation metrics such as accuracy, precision, recall, and confusion matrix were used to assess model performance.
